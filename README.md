# 🎯  Ad Click Predictor (Logistic Regression)

📊 A machine learning project focused on predicting user interactions (clicks) with online advertisements based on demographic, behavioral, and contextual data.

**Dataset Overview**: This dataset captures user behavior and online ad interactions, ideal for binary classification tasks. The goal is to improve ad targeting strategies and optimize placements.

**Dataset Source**: [Advertisement Click on Ad Dataset (Kaggle)](https://www.kaggle.com/datasets/gabrielsantello/advertisement-click-on-ad)

## 📁 Project Structure

* `ad_click_analysis.ipynb`: Main script containing data exploration, visualizations, and Logistic Regression implementation.
* `advertising.csv`: Dataset including user demographics, browsing habits, and ad details.

## 📈 Key Insights

* **Predictive Model:** Built a Logistic Regression model to classify whether a user clicks on an ad or not.
* **Demographics Analysis:** Examined how age, gender, and income influence ad clicks.
* **Behavioral Analysis:** Correlated time spent on the site and internet usage with user interaction.
* **Visualization Highlights:** Utilized Seaborn and Matplotlib to create pairplots, histograms, and jointplots for deeper insights.
* **Model Performance:** Evaluated the model using a classification report and confusion matrix to gauge precision, recall, and F1-score.

## 🛠️ Tools Used
